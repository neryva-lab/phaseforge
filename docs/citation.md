# Citation

This document explains how to cite this work.

## Current state

No paper title, authors, venue, or year are recorded anywhere in the repository. These facts must come from the author and are not inferred here.

## `CITATION.cff`

Citation metadata for this repository belongs in `CITATION.cff` at the repository root, using Citation File Format 1.2.0. The `title`, `authors`, `venue`/`journal`, and `year` fields are marked TODO pending the author's input. Once `CITATION.cff` is filled, GitHub renders a "Cite this repository" widget from it.

To complete the citation record: fill the TODO fields in `CITATION.cff` with the paper title, author list, venue, and year, then keep the plain-language summary in this file in sync with those values.
